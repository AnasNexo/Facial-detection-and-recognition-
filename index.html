Quickstart

Up and running
in minutes.

01

Install dependencies

FaceNet weights (~90 MB) are downloaded automatically on first run.

pip install -r requirements.txt
02

Collect face images

Opens your webcam and captures 100 face images per person using MTCNN detection. Vary your expression and angle slightly for better accuracy.

python face-dataset.py --name daniel --samples 100 python face-dataset.py --name mark --samples 100
03

Preprocess

Detects and aligns faces using eye landmarks, crops to face region, resizes to 160×160, and normalises pixel values for FaceNet.

python face-preprocess.py --names daniel mark # or auto-discover all folders: python face-preprocess.py --auto
04

Train and save the model

Extracts 128-d FaceNet embeddings for every image, trains an SVM classifier, runs cross-validation, and saves the model bundle.

python face-train.py
05

Recognise in real time

Opens webcam, detects faces, runs them through FaceNet + SVM, and overlays the person's name with confidence %. Faces below 70% show as Unknown.

python face-recognition.py # Press Q to quit

Model

Transfer learning.
Zero training from scratch.

🔍

MTCNN

Multi-task Cascaded Convolutional Network. Three-stage cascade detects faces and 5 facial landmarks (eyes, nose, mouth corners) in a single pass.

Detection
🧬

FaceNet / Inception-ResNet-v1

Pretrained on 3.3M faces across 9,131 identities using Triplet Loss. Maps any face to a 128-d embedding where same-person faces cluster together. Used frozen — no retraining.

Transfer Learning
⚡

SVM Classifier

RBF-kernel Support Vector Machine with Platt scaling trained on your embeddings. L2-normalises inputs first. Returns calibrated probability scores per identity.

Classification
🛡️

Unknown Rejection

Any face where max class probability falls below the threshold (default 70%) is labelled "Unknown" in red. Prevents confident mislabelling of strangers.

Safety

Built with FaceNet · MTCNN · scikit-learn · OpenCV
